# Indo Japan Shito Ryu Karate Do · India (IJSRKDI)

Marketing website for the Shito-ryu karate school with dojos in Coimbatore, Kotagiri, and Mettupalayam.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Pages

- `/` — Home
- `/about` — School & Singapore Shitoryu Association affiliation
- `/programs` — Kids & adults
- `/locations` — Coimbatore, Kotagiri, Mettupalayam
- `/contact` — Contact placeholders (to be updated)
